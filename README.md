# ALife Pond

A browser-based artificial-life sketch built with p5.js.

Creatures seek food, spend energy, reproduce, die, and pass mutated genes to their offspring. The genome affects motion and visible anatomy: body length, width, head size, tail length, eye spacing, sensor field, markings, color, speed, sensing range, efficiency, and turning rate.

Run locally:

```sh
python3 -m http.server 8080
```

Then open `http://localhost:8080/`.
